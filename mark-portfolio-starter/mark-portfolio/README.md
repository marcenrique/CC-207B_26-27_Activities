# Mark Henry Alejandro — Portfolio

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Download or clone this project.
2. Open the `mark-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Personalize before publishing
- Replace `assets/images/profile-placeholder.svg` with your own portrait, preferably named `profile.jpg`.
- Update the portrait `<img>` source in `index.html` to `assets/images/profile.jpg`.
- Replace `your.email@example.com` with your actual public contact email.
- Add your GitHub and other professional profile links when ready.
- Review every project and skill description. Keep only accurate details.
- Add project screenshots and repository links after confirming they are ready to share.

## Files
- `index.html` — page content and structure
- `css/style.css` — styling and responsive layout
- `js/script.js` — mobile navigation and scroll reveal
- `assets/images/` — profile and project images

## Technologies
HTML5, CSS3, JavaScript (vanilla)
